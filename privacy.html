저장 및 서비스 이용

Google OAuth 인증정보는 GitHub의 암호화된 Secrets에 저장하고 작업 실행 시 사용합니다. 로컬 인증정보는 Windows 사용자 암호화 저장소를 사용합니다. 작업 상태와 제작 소스는 Supabase의 비공개 저장소에 보관하고, 영상은 운영자의 YouTube 채널에 업로드합니다. GitHub Actions에서 제작·예약 작업을 실행합니다.

이력 보관과 연결 해제

예약·게시 이력은 중복 방지와 운영 기록을 위해 보관합니다. 운영자는 각 서비스에서 저장 자료와 인증정보를 관리·삭제할 수 있습니다. Google 계정의 서드 파티 연결 관리에서 앱의 접근 권한을 철회할 수 있습니다.

Google API 이용

Google API로 받은 정보는 운영자 본인의 채널 관리 목적에 사용합니다. 자동화 코드에서는 이 정보를 광고나 모델 학습에 사용하지 않습니다. Google API 데이터의 사용은 Google API Services User Data Policy 및 Limited Use 요건을 따릅니다.
